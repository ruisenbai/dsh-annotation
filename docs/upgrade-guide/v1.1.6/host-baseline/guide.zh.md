# 宿主基线与统一正文选区操作栏

[English](guide.md) | 中文

## 变更

最低宿主从 `0.2.1-rc.2` 调整为 `0.2.2-alpha.2`，Node.js 要求为 `>=24.9.0`。统一的“引用文本 / 添加注解”操作栏需要 master 提交 `f3803c96974ad4a94195fb97e5c637e9c2a3afe3` 中的选区接口。已发布的 `0.2.2-alpha.2` 系列包含该接口。宿主检查或发送消息期间，附加和编辑操作保持锁定。注解协议 v5 和浏览器存储 v6 不变。

## 迁移

1. 检查 `dsh --version` 和 `node --version`。宿主仍为 `0.2.1-rc.2` 时，保留插件 1.1.5。
2. 先升级到 DSH `0.2.2-alpha.2` 或更新版本，再安装 1.1.6。开发者可以使用仓库锁文件中的注册表依赖，或采用[官方源码验证流程](../../../development.md#official-source-verification)。
3. 刷新 Web 页面，选中已完成模型回复中的文本，确认只有一个操作栏，包含“引用文本”和“添加注解”。引用将片段插入主输入框，添加注解打开编辑器。保留现有浏览器存储和会话数据。
