# 侧边注解

[English](guide.md) | [简体中文](guide.zh.md)

## 变更

**在侧边聊天提问** 改为 **在侧边添加注解**。保存的侧边注解使用普通注解记录和发送流程。消息的 `source.sessionId` 标识原文所在对话，与接收注解的会话分别保存。新提交使用协议 v6，注解存储写入 v7；旧版插件无法读取这些新数据。

没有冻结请求的待发送侧边引用会转换为只含原文、尚未填写意见的注解。旧的冻结重试、发送结果未知的请求和已发送历史保留原始内容。现有侧边聊天、草稿和关联仍可使用。

## 迁移

1. 同时更新 `dsh-annotation` 的宿主端和客户端，再刷新网页。迁移后避免旧版插件页面继续写入同一份浏览器存储；新记录不支持降级读取。
2. 打开侧边聊天，检查注解记录。待发送引用只有在注解保存成功后才会移除。若存储失败，请保留浏览器数据，解决存储问题后重新打开或重试该聊天；转换会复用稳定标识，不会重复生成。
3. 如有冻结重试，请通过原有操作处理。不要仅因响应丢失，就用新的发送替换结果未知的请求。
4. 在主对话回复中选中文字，点击 **在侧边添加注解**，确认编辑区显示的接收聊天和原文。保存注解、定位原文，再从侧边输入框发送，验证新流程。

版本处理详见[持久化变更确认](../../../compatibility.md#cross-conversation-annotation-persistence-acknowledgement)。
