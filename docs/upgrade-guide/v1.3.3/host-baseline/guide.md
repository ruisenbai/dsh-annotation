# Upgrade to DSH Annotation 1.3.3

English | [简体中文](guide.zh.md)

Use stock DSH `0.2.3-alpha.2` or later and Node.js `^24.22.3 || >=26.13.1`. Keep the 1.3.2 build on DSH `0.2.2-rc.5`.

The Host and Web client read the same five deployment fields. Existing field names, drafts, Session history and side-chat associations do not require migration. A batch above the configured limit stays in the composer; reduce the selection or raise the limit before sending.
