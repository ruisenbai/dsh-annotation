# 升级注解插件所需的宿主版本

简体中文 · [English](guide.md)

## 变更

从 1.3.1 更新到 1.3.2 时，DSH 的最低版本由 `0.2.2-rc.4` 升到 `0.2.2-rc.5`。1.3.2 使用新版会话组件在侧栏显示独立会话，Node.js 最低版本为 `24.9.0`。仍在使用 `rc.4` 的用户可继续使用 [1.3.1](https://github.com/ruisenbai/dsh-annotation/releases/tag/v1.3.1)。

## 迁移

1. 桌面版在设置中查看 DSH 版本。Web 版运行 `dsh --version`。先更新到 `0.2.2-rc.5` 或更高版本。
2. 安装 1.3.2，再打开应用或重启 Web 服务并刷新。主会话中的草稿、侧聊与注解记录会沿用现有数据。
3. 在主会话选中文字并点击“在侧边添加注解”，核对编辑框在原文旁。新建侧聊，确认正文从空白开始且能正常发送。
