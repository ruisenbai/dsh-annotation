# 宿主基线与子会话选区

[English](guide.md) | 中文

## 变更

最低宿主要求从 `0.2.2-alpha.2` 提升到 `0.2.2-alpha.3`，Node.js 要求为 `>=24.9.0`。验证基线为 master 提交 `8bd073392eef6f54e921a093b95076248eb08cbb`。其中可继续交互的子会话不再提供父会话可用性字段；“引用文本”和“添加注解”沿用宿主当前的选区规则。一次性、类型未知和已移除的会话保留各自限制。仅凭已发布的包版本号无法确认是否包含这项 master 变更。

记录统一按创建时间从新到旧排列，使用附加控件，不再显示发送状态文字和分组。可用注解在发送后仍能再次附加。回答中的注解链接显示为蓝色加粗文字，不带下划线，并保留预览和原文定位。注解协议 v5 和浏览器存储 v6 的格式保持不变。

## 迁移

1. 检查 `dsh --version` 和 `node --version`。仍使用 DSH `0.2.2-alpha.2` 时，保留插件 1.1.6。
2. 安装 1.1.7 前先更新宿主。开发者验证最新 master 时，使用固定提交的检出及[官方源码验证流程](../../../development.md#official-source-verification)。
3. 重启该 profile 并刷新 Web 页面。在已完成的回复中选择文字，确认只有一个提供“引用文本”和“添加注解”的工具栏，并在可继续交互的子会话中重复检查。
4. 附加一条已保存注解，发送后再次附加。确认记录总数、注解身份保持不变，以及回答链接呈蓝色加粗。保留现有浏览器存储和会话数据。
