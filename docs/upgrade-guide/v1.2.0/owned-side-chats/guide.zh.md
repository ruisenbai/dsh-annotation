# 侧聊归属与上下文

[English](guide.md) · 简体中文

## 变更

插件 1.3.1 要求 DSH `>=0.2.2-rc.4` 和 Node.js `>=24.9.0`。它在原版 DSH 中提供工作区列表筛选和侧聊正文起点。

## 迁移

1. 更新 DSH 到 `0.2.2-rc.4` 或更新版本，安装插件 1.3.1 的完整安装包，然后重新打开桌面版或重启 Web 并刷新页面。
2. 在原主会话的右侧栏打开已有标签。它们继续使用原记录。点击 **＋** 创建新侧聊，继承此时已经保存的历史。
3. 从原主会话进入侧聊。悬停标签可独立打开或归档，在侧栏的 **已归档** 中恢复。迁移旧标签时请保留浏览器站点数据，其中包含旧会话的关联和草稿。
