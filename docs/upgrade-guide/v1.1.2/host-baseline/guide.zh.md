# 升级注解插件的宿主基线

[English](guide.md) | 中文

## 变更

插件 1.1.2 面向 DSH `0.2.1-alpha.2`。1.1.3 要求 `>=0.2.1-rc.2`，并使用宿主当前的输入框和消息渲染接口。浏览器存储 v6、提交协议 v5、草稿、回收站记录及固定重试内容均沿用现有格式。

## 迁移

1. 确认宿主版本为 `0.2.1-rc.2` 或更新版本。仍使用 `0.2.1-alpha.2` 时保留插件 1.1.2；通过正常更新流程升级完整宿主。
2. 使用原有 Web profile，按照 [README 命令](../../../../README.zh.md#installation)安装 1.1.3 GitHub 发行包。
3. 重启该 profile 正在运行的宿主并刷新浏览器页面。保留浏览器站点数据、会话日志及 profile 设置。
4. 确认 `why dsh-annotation` 解析到 `1.1.3`。打开 **设置 → 注解**，检查保存的记录，并将一条注解与输入框文字和附件一起发送。
