# 决策 0004：使用宿主输入框与附件接口

已采用。这里记录 0.1.3 时代的迁移，当前重试身份规则见[提交内容](../data-model.md#submission-payload)。

## 背景

宿主将图片发送扩展为有顺序的图片和文件附件，并切换为可编辑的结构化输入框。校验、上传及显示原本就由宿主管理。

## 决定

插件沿用标准消息和命令附件通道，冻结提交所需的信息。附件二进制不进入浏览器的注解重试元数据。先前只记录数量与类型的历史记录只能按这些事实校验；较新的记录增加了内容身份与名称。

恢复光标时使用宿主标记和浏览器选区，只尝试原来仍可编辑、内容未变且未被用户主动移开焦点的输入框。隐藏命令标记不计入可见偏移，不替换编辑器文档和引用组件。

## 影响

宿主继续负责上传、消息附件、可编辑文字与引用；插件负责选区、注解及冻结记录。升级时验证混合附件顺序、缺失和不匹配的重试、旧图片记录，以及移动焦点后不抢回输入。
