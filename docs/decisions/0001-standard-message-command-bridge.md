# 决策 0001：从官方输入框发送注解

已采用。本文记录最初的设计；当前消息与附件格式见[数据模型](../data-model.md)。

## 背景

用户应能用同一个输入框发送普通文字、附件和注解。宿主需要留下可重放的模型输入；浏览器刷新或重复提交不能产生两条任务。

## 决定

通过宿主的输入框命令机制声明当前会话的注解，使用原有的发送按钮和回车操作。内部命令对接收会话、大小和内容进行验证，以从提交标识派生的固定消息标识走标准 `followup` 路径。只有宿主队列和持久化用户消息能证明排队或送达。普通斜杠命令不夹带注解。

## 影响

插件列表负责管理注解，不再拥有独立任务输入框。只含注解也能发送。重试保留固定数据，缺少附件时提示重新选择。宿主不提供隐藏命令入口时，这条内部命令可能出现在命令搜索中；不合要求的手动调用会被拒绝。
