# Support

## Questions and setup help

Open a [GitHub Discussion](https://github.com/ruisenbai/dsh-inline-comments/discussions) with:

- DSH version and installation method;
- plugin version or commit;
- browser and operating system;
- relevant plugin configuration;
- a minimal reproduction with sensitive text removed.

## Bugs

Use the bug report issue form. Include the browser console error and the affected Session state (`idle`, `running`, waiting, or archived). Do not paste private prompts, selected text, credentials, or complete Session logs into a public issue.

## Security

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).

This volunteer project provides no guaranteed response time or commercial support SLA.
